# 學測英文自學站

學測英文單字與文法的互動學習網頁，透過 GitHub Pages 發布。

| 檔案 | 內容 |
|---|---|
| `index.html` | 首頁，連到下面三個學習頁 |
| `vocab-a.html` | 學測英文 A 級必背 244 單字互動學習系統 v1.1 |
| `vocab-b.html` | 學測英文 B 級重要 1032 單字互動學習系統 v1.0 |
| `grammar.html` | 學測英文文法專題測驗 |

更新某一頁時，用新版內容覆蓋同名檔案即可，首頁連結不必改。

A、B 級單字頁有「匯出進度／匯入進度」：匯出存成 JSON 備份檔，匯入時會檢查是否為同一級的單字，並取代目前裝置上的紀錄。

A、B 級單字頁有「🖨️ 列印字卡」分頁：可依週次、待加強或排名區間選字，印成對折字卡（每頁 8 張）或自我測驗單字表（每頁 36 字，中文可留白）。列印時縮放請選「實際大小／100%」。
