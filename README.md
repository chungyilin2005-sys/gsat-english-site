# 學測英文自學站

學測英文單字與文法的互動學習網頁，透過 GitHub Pages 發布。

| 檔案 | 內容 |
|---|---|
| `index.html` | 首頁，連到下面四個學習頁 |
| `vocab-a.html` | 學測英文 A 級必背 244 單字互動學習系統 v1.1 |
| `vocab-b.html` | 學測英文 B 級重要 1032 單字互動學習系統 v1.0 |
| `vocab-c.html` | 學測英文 C 級補強 807 單字互動學習系統 v1.0（歷屆未考過的字，例句為自編） |
| `grammar.html` | 學測英文文法專題測驗 |
| `tools/` | 把題庫資料同步到網頁的小程式（見下方） |

更新某一頁時，用新版內容覆蓋同名檔案即可，首頁連結不必改。

A、B、C 級單字頁有「匯出進度／匯入進度」：匯出存成 JSON 備份檔，匯入時會檢查是否為同一級的單字，並取代目前裝置上的紀錄。三級的進度分開存，互不影響。

A、B、C 級單字頁有「🖨️ 列印字卡」分頁：可依週次、待加強或排名區間選字，印成對折字卡（每頁 8 張）或自我測驗單字表（每頁 36 字，中文可留白）。列印時縮放請選「實際大小／100%」。

## C 級頁面和 A、B 級的差別

A、B 級的字都考過，所以頁面圍繞歷屆考頻（積分、出現場次、正解次數）設計。C 級的字全部沒考過，改為：

- 排名與週次依「建議優先度（高／中／低）」，同優先度再依日常使用頻率（Zipf 值，越大越常見）。
- 「分析」分頁顯示優先度與日常頻率分布，不再有考頻積分。
- 例句是自編例句，並附中譯；目標字以粗體標出。
- 共 21 週（每週 38–39 字）。優先度「高」的字排在前面。

## 同步題庫資料（tools/）

題庫的正式資料在 Excel 母檔，網站 `vocab-quiz` 儲存庫的 `data/*.json` 由母檔轉出。這裡的頁面各自內嵌一份資料，母檔或 `vocab-quiz` 有修改時，用下面的程式同步，不要手動改頁面裡的資料。

| 程式 | 用途 | 指令（在本資料夾內執行） |
|---|---|---|
| `tools/sync-ab-from-quiz.js` | 把 `vocab-quiz` 的 A、B 級詞性與例句同步到 `vocab-a.html`、`vocab-b.html`。只改這兩欄 | `node tools/sync-ab-from-quiz.js check <vocab-quiz資料夾>` 先看會改幾處，改成 `apply` 才寫入 |
| `tools/sync-c-data.py` | 把 C 級母檔（`C級題庫_母檔.xlsx`）的資料寫進 `vocab-c.html`，並重新分週 | `python tools/sync-c-data.py <母檔路徑>`，加 `--check` 只比對 |

需要 Node.js 與 Python 3，不用另外安裝套件。改完請在本機開啟頁面確認，再 commit 與 push。
